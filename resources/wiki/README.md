## 图鉴拓展

---

<details><summary>图鉴查询</summary>

> 只有安装了对应游戏的资源才能在图鉴查询中查询到对应游戏的内容

> 部分物品无法显示图片是正常现象

### 指令
~~~
#图鉴查询***
~~~

### 查询

支持别名查询（小爱同学——>爱弥斯）

关键字查询（岸——>守岸人）

支持 名字+专武 查询关联武器如（莫宁专武——>宙算仪轨）

支持 别名+专武 查询关联武器如（小画家专武——>琼枝冰绡）

### 翻页

指令后使用 第X页 进行翻页(例：`#图鉴查询***第5页`)

仅支持数字，请勿输入中文数字或数字符号(壹二³Ⅳ⑤...)

### 示例
~~~
#图鉴查询卡
~~~

![这里放卡图片](https://gitee.com/liangshi233/panel-img/raw/master/resources/wiki/2.jpg)

<details><summary>鸣潮图鉴</summary>

首次使用前需手动为miao-plugin更新对应游戏必要资源(一键更新 或 安装[meta-mc](https://github.com/Kukukij/meta-mc))，未来版本资源需手动使用指令更新(详见主页`一键更新未来角色的数据`功能)

<details><summary>一键更新</summary>

#### 安装必要资源

~~~
#一键更新鸣潮新版本完整数据
~~~

#### 更新后续资源

~~~
#一键更新鸣潮新版本数据
~~~
</details>

### 指令
~~~
#鸣潮XX图鉴
~~~

支持别名，支持自动查找种类，支持别名+专武
