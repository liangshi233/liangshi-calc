# * Determine

### 目标特殊元素状态

---

<details><summary>使用类型</summary>

##### 可用类型

处于燃元素(燃烧)下触发的buff

处于冻元素(冻结)下触发的buff

处于激元素(激化)下触发的buff

##### 可用举例

| 类型  |       使用举例       |
|:---:|:----------------:|
| 燃元素 | BurningDetermine |
| 冻元素 | FreezeDetermine  |
| 激元素 |        /         |

##### 关于目标特殊元素状态buff

一般此项仅在特定反应特化.角色和组队计算中才指定

同时满足触发条件时按 燃元素>激元素>冻元素

</details>

---

<details><summary>Buff侧设置</summary>

##### 通用配置

冻元素(冻结)
~~~~~~~~~~
params.FreezeDetermineDetermine === true ? true : false
~~~~~~~~~~

燃元素(燃烧)
~~~~~~~~~~
params.BurningDetermineDetermine === true ? true : false
~~~~~~~~~~

</details>

---

<details><summary>Dmg侧设置</summary>

此项可留空，留空默认false

</details>
