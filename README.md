优化超全计算中dph,dps计算

优化超全计算中单人循环流畅度(单人循环充能进度)的计算

增加自定义调整计算条目内容，自定义调整排行规则，更多条目名称展示格式

为`丝柯克`适配符合条件时自动提升技能等级(需miao-plugin中更新丝柯克的data.json)
